NFCTools

NFC diagnostics, virtual tag emulation and magic-card cloning

v0.7.14~beta+210RootlessRoothide

NFCTools is a native SwiftUI toolkit for NFC on iOS: read and inspect tags, keep a library of them, emulate saved tags as virtual cards, and clone UIDs to magic cards.

This is the jailbreak-repo build of the app, installed to Applications. The Control Center tiles and nfctools CLI come from the separate NFCTools Plus package, which installs alongside it.

> After installing, do a userspace reboot (Restart / ldrestart). The Home and Lock Screen widgets ship as an app extension that only registers after a userspace reboot — a respring is not enough, and until then the widget preview shows blank.

Tag diagnostics & scanning

  • Detects ISO 14443 Type A/B, ISO 15693, FeliCa and MIFARE.
  • Reads UID / PUPI, ATQA, SAK, memory layout, manufacturer info and NDEF records. Long-press any value to copy it.

Virtual tag emulation

  • Broadcast a saved tag's UID to external readers and other phones.
  • A Type 4 NDEF applet answers SELECT / READ BINARY so readers can read the tag's NDEF data.
  • Haptic feedback the instant a reader makes RF contact.

> On iPhone, the card type (ATQA/SAK) is set by the NFC controller, not the app — an emulated tag always presents an ISO-DEP (Type 4) SAK so NDEF works. Readers that only check the UID work; readers that require an exact ATQA/SAK or MIFARE Classic won't. For an exact copy, clone to a Gen4 UMC magic card.

Tag library & cloning

  • Local encrypted vault with nicknames, 50+ glyphs and color accents; portable .nftag export/import.
  • Clone custom UIDs to magic cards: Gen3 APDU, Magic Type 2 (NTAG21x / Ultralight) and Gen4 UMC.

Native experience

  • 100% SwiftUI, light/dark themes, VoiceOver and Reduce Motion support.
  • Home Screen and Lock Screen widgets (iOS 16+) for one-tap emulation.

Requirements

  • An iPhone whose NFC controller supports direct access (iPhone 12 / 13 and newer). The in-app Diagnostics page tells you what your device supports.
